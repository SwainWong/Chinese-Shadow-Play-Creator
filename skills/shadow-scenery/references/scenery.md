# 房屋、山丘、寺庙与花草景片

先确定这一镜中观众该看谁、人物要从哪里经过、哪件景物会回应动作。新题材用相关流派的影箱、艺人资料或馆藏校准形制。现有公共试影提供可拆用的六张透明皮片和两镜布置。[《山门一阵风》工程](../studio/index.html)

| 景物 | 怎么画和装 | 怎么验 |
|---|---|---|
| 民居 | 先画低檐、门槛与窗格。瓦面、承重柱和大块墙皮连成可立住的整片，花窗留实桥。门洞做透孔，窗纸另保留浅皮色。 | 单显建筑，在门后放深浅两种景，检查孔中能看到后景；同台放定样角色比较冠顶、门楣、台脚。人物若要真正穿门，另排进门线路、层序与门槛。 |
| 山丘 | 远山取长而缓的外脊，降低纹样密度和对比；近丘可用起伏更陡的轮廓及贯通的镂线。给两层各画一条天际线。 | 单显远、近两层，再合看；缩到播放尺寸，检查连续山脊有没有贴住人物的眼、棍梢或屋檐。在固定摄影机的静景里锁住山根。 |
| 寺庙 | 用山门、柱础、重檐和内院正殿表达纵深。排好正殿与门洞，再把山门压在前面。梁柱固定；需表演的幡、帘、檐铃单列皮片，挂点落在实梁或檐底。 | 隐藏山门看正殿全形，再开山门检查露出的屋脊、入口与柱边。声响对齐可见摆动。确定流派、时代或建筑名称前，保留原创舞台编排的标注。 |
| 花草 | 留出叶脉、花头与茎的负形。扎根处和底座固定，花枝从有实皮的分叉起摆，另一丛草可以稍迟受风。枝条幅度按镜头大小调试。 | 风起、摆到极值、收风各看一次。固定根部前后取样须稳定；转轴附近要看得见搭接。复看花头有没有遮脸，草尖有没有把落足轮廓割碎。 |

**同幕材质。** 用同一张灯幕检视轮廓、皮色与镂孔。艳色可留给建筑识别部位和花头，远山适当降低对比。正面切片按原始宽高比摆放，避免拉扁庙门去迁就握棍或走位；改摆位、尺度、层序或另画景片。镜头中景片和演员对光质的反应应协调。

**交付与局部改动。** 记录每片的源图、透明裁切、宽高、挂点或根点、前后次序、动作触发和收势。保留一张干净成片图、一张分件图和可开关各层的舞台。逐帧查发生交互的区域；有意穿门、遮挡或触碰应按指定时段核对。样例里的透明度、风摆角、建筑与人物的尺寸只随本台口使用。更换影箱、机位或主角尺度时重新定标。

华县汪天喜的《花园》展示用院门、走廊、阁楼组合舞台景片的做法；密歇根大学艺术博物馆的花瓶景片记录了雕刻、彩绘驴皮的使用。两项资料用作工艺参照。本次房屋、庙宇和牡丹为新制数字景片。[华县皮影展](https://artsandculture.google.com/story/YQXxSQbOimSrJA?hl=zh-CN) · [UMMA 馆藏 1998/2.60](https://umma.umich.edu/objects/shadow-puppet-vase-with-flowers-1998-2-60/)
