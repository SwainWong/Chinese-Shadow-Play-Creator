# 关节、身段与成片复核

每尊偶先画一张能说清角色朝向、支撑足和近远手的自然定势。在这个姿势上确定局部正向、针距、可弯的一侧和可用角域。人、兽、妖、菩萨和换身后的新偶各有自己的基准。树枝、衣摆、道具如设活动点，也登记父片、轴心、可摆范围、接触或停止条件。

| 观众看见的疑点 | 怎样定位 | 怎样返修 |
|---|---|---|
| 肘、膝朝错的一侧，或快转时抽动 | 在整段每个输出帧还原偶自身坐标，分别读近远侧铰链的有向角、针距和相邻帧转角。对照定样弯向；始终弯错也可能非常平滑。翻至刃面时用投影前数据，同时复看翻面前后两靴和脸的朝向。 | 重选肘膝弯向、调动作目标、延长过渡；达到限位仍够不到就换步、换片或换整偶。 |
| 腕、头、靴子像断开或反折 | 除针点重合，还看实际透明皮片。单显脸、颈舌、衣领和手片，检查极限姿势仍有实皮搭接。分开量前掌朝向、靴踝到膝的方向，逐脚注明是否落地。 | 加宽被覆盖的皮缘，改腕针、靴口或鞋面朝向；翻面时重新排遮盖顺序。 |
| 始终窝着、飞行像整偶被吊走 | 在相同地线比较站、蓄、蹬、飞、落的剪影；标最后着地和首次离地帧。着地的一脚锁台面，髋先移重。看两腿或两臂之间是否能透出幕光。 | 青年僧人站定伸腿，金池微偻，悟空有猴步与独足亮相。腾云先以支撑脚蹬伸，再让另腿错拍收展，落地先触台后接重。熊依掌底步态或披甲身排。 |
| 棒一直绕中点转，或双臂在关键拍读成一臂 | 登记杆长、前后握点、执握与松开时段，量棒端相对腰的轴向进出、支点到台板或云片的距离。正拍同时看两只手、两截袖和眼鼻。接物或会招检查接前、相接、分开，视听在同一拍。 | 分配送杆手与承持手；一手执稳时另一手能开、移、再扣。调整握距、肩位、层序和演员让位；正拍留出可读的轮廓。 |
| 数值正常，画面仍怪 | 先原速看干净 MP4，再慢放相邻帧，开铰点或单显前后片。重点查长期遮脸、远袖藏进胸片、提靴消失在袍里、持物滑出掌心、脚底滑台、角色与对白指向不符。 | 用相同镜头、比例和帧号输出修前修后；需要看节奏时用同步短片。最终检查对应新版成片，写下仍影响阅读的帧。 |

## 悟空十五式的已知反例

在插件根目录运行 `node skills/shadow-audit/scripts/check-wukong.cjs`。它直接加载随插件发布的悟空十五式，检查 1,440 帧的肘膝弯向、靴踝、皮片针距、执握点及落足。可传一个十五式工程副本的目录复测。查看各式靴尖反折的次数可在该副本运行 `node production/ankles.cjs .`。适用角域只属于此偶。腕针周围皮片是否真正搭接、额部是否被袖子遮住，另用实际成片与皮片遮罩核对。

旧版同样的 2,880 个单脚样本有 236 个折向错误一侧，修订版为零。复看第十式腾云后靴、第十三式登棒和第九式独足承重。举棍短暂遮脸和耳侧手在全景偏小仍需在相关返修中目测。

## 四折第三折的独立复测

《洞前斗法》的悟空与披甲熊同台，使用四折工程自己的猴偶和调度。此版已有起飞时序、接地与碰点检查。另用本 skill 内的摆靴检查脚本，读取实际动作函数返回的踝、膝与鞋底方向，分别统计全折以及高处腾云段。如果有原四折工程，可在本 skill 目录运行以下命令。该探针需要四折专用的第三折调度和悟空坐标。

```sh
python3 scripts/check_cave_boots.py /path/to/black-wind-four-04
```

输出 JSON 按近远脚列出镜内帧号（从 0 起）。退出码 1 表示检测到反折，0 表示本项通过；2 表示输入或项目结构不符合此专用检查。

2026-11-23 回查这份既有工程，第三折 624 帧共 1,248 个单脚样本，有 125 个靴踝夹角小于等于零。高处离地的第 477–535 帧中，后靴有 48 帧折向异常，近靴为 0。第 489、517 帧后靴都约为 −125.6°。干净成片第 517 帧里后靴与袍摆相叠，局部轮廓难辨。**这是四折旧镜的待修项**。下次用这折做腾云时，在副本修后靴、与原镜同拍对照，再分别复查其他三折与碰点。

## 如何记一次审片

每条意见记录版本、镜头与帧或时间码、近远侧、正常应看见什么、实际看见什么、改动位置、复核人和结论。多人审片分别看参考与造型、骨架与接触、干净成片与声画；将意见落实到重导后的文件。分别记录程序扫描、成片抽帧、原速观看、实际试听和用户确认。跨镜返修另核对未改镜的复用记录。初次完成导出或通过角度检查，只能证明相应项目已经验证。
