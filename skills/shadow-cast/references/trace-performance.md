# 参考片身段量取与分件

用于制作指定角色的短段复刻。先选动作有明确起止、支撑足与持物手可辨的镜头。每段保留来源文件、从零起的首末帧、参考帧率、原画面尺寸和取景矩形。用同一解码基准生成测量帧与审片帧，可取首、中、末三帧检查一帧错位。

1. 先从指定图生成可分离的皮片。用截图中的眼、颈口、腰、腕、膝、靴口、靴尖、道具两端做一张同姿装配，比较外形和层次。动作中需要改变遮挡时，给相应皮片独立铰点。
2. 以原片屏幕像素记录每个取样姿势。两侧固定使用各自的肩肘腕和髋膝踝，另记眼点、靴尖、两端棍位与握持身份。把看不清的点或无法区分的棍端记为推定。保持段标起讫，换重、快转和动作突变处逐帧取样。
3. 先锁支撑足，再排腰与摆动足。靴口和靴尖共同决定鞋面方向；接触台板时以鞋底取样校准。单足定势仍要复核空手、视线和道具的独立轮廓。
4. 棍用中心、角度和投影长度插值，握点对准棍轴。深俯和反仰时检查脸、颈舌和领口。长颈舌露到后脑时，可将脸冠与颈片分开，使耳下接点随脸转、颈根仍被衣领盖住。
5. 使用相同取景、相同帧号输出参考与复刻对照，既看低位也看过渡。为每镜保留姿势源、独立输出与重渲入口。以上做法源于二维可见投影，实体偶的实物结构需要另有制作依据。
