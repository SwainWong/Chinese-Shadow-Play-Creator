# 皮影身段与调度

先在单镜时间线上排脚，再排腰、眼、手和道具。划出最后着地、离地和接重帧。杆件登记两端与双手握位；前送、移握和旋转各有独立轨迹，检查杆端相对腰的位移。换面时随整偶转换局部弯向。做对手戏时先排一方的动作及另一方的回应，再看接触与回收。

[悟空十五式审片台](studio/index.html)可选式、慢放、逐帧看近远关节。复制 studio 到本集，改 production/moves.js 对应式，`python3 production/render.py 10` 单独输出第四十秒附近的第十式；无参数输出全片。击点改变先运行 `python3 production/score.py 10`。十五式均渲染后自动合片。最后用[关节审查](../shadow-audit/SKILL.md)复核。新编角色先按自己的针距重新定标。
