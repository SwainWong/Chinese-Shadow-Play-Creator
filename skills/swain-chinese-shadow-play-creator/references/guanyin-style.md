# 《初入觀音禪院》續修定樣

本表用於《影神圖》第一期〈金池長老〉開場。創作者以第三版認可的風格和人物比例為此次聲音返修的基準。續集或另一齣戲若要借用，可先以自己的定樣鏡核對。

| 核對項 | 本場已定的做法 |
|---|---|
| 影偶與同台比例 | 取第三版對應鏡位、同一動作拍點的畫面作對照。記錄三藏、悟空、白馬與山門的相對身量、足底和鞍座高度。沿用分件、鉸點及縮放參數。 |
| 真皮影質感 | 人物、建築、雲柳、觀音、寺鐘與懸槌共用背光皮幕的透光、鏤刻和皮邊質感。精細道具仍要看得出皮片刀口。 |
| 山寺與陳設 | 山路經外門、石階及台基通到正殿。匾額「觀音禪院」隨整座殿門生圖，字跡與殿門同受歲月磨損。禮佛鏡中的觀音正面朝觀眾；撞鐘移至側殿，讓懸槌有接觸和回擺的空間。 |
| 字幕 | 原頁繁體，略粗宋體。白字落在貼合字幕行寬的黑底上，字幕收起時露出戲台。 |
| 聲場 | 低沉普通話說書人按意群推進。悟空、三藏各用獨立音色，配古風撥弦與簫。聲音返修可調句間留白、鏡頭停留與聲點。 |
| 審看 | 構圖審看者沿路徑查遮擋、前後層和落地；材質審看者逐件查整場皮影質感。聲音返修對照已定美術和同台比例，另聽定稿錄音。 |
