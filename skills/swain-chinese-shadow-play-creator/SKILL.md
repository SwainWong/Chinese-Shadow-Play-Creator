# Swain-Chinese-Shadow-Play-Creator

先确认本次交付的是新戏、试偶还是已有片段的返修。保留用户提供的完整口播和顺序，标出念白、唱段与舞台指示。已有参考片先看整段的身形变化，再选动作差异足够大的镜头。镜内时间从零起算。约十秒适合试景试偶，对话与交锋分场可用十五至三十秒。

| 制作环节 | 用法 |
|---|---|
| 定身份和拆片 | 用[角色影箱](../shadow-cast/SKILL.md)选人、兽或披甲身，先定同台比例，再定每枚针和遮盖顺序。 |
| 置景 | 用[舞台景片](../shadow-scenery/SKILL.md)分远山、近丘、前后殿与花枝，给发言与执物手留出亮幕。 |
| 排表演 | 用[身段与调度](../shadow-performance/SKILL.md)安排起势、接触、收势。每一拍可追溯到关节或道具轨。 |
| 审片 | 用[关节与成片审查](../shadow-audit/SKILL.md)查实际帧、搭接、正反面与握点，把意见落实到新版成片。 |
| 出片 | 用[口播渲染与局部合片](../shadow-film/SKILL.md)生成带声 MP4、分镜、HTML 与源文件。 |

ImageGen 可用于原画与透明皮片。用可复现的 JS 和 Canvas/WebGL 排动作。已有作品的返修从对应版本复制，保留美术、音轨和原镜。为每镜登记演员、支撑足、近远手、接触对象、声点与持续时间。提供单独重渲目标镜的命令，以及可对照的同机位新旧画面。正式节目按所在项目的集数和归档约定存放。

每轮反馈记版本与帧号。角色专用参数保存在对应影箱，能复现的跨集做法写回相关 skill 并更新插件版本；保留旧例检验新规则。区分程序检查、实际视听和创作者确认。
